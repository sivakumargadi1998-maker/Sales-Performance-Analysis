# Sales Performance Analysis Dashboard

## Project Overview

This project analyzes sales data using Microsoft Excel 2016 to understand business performance and identify sales trends.

## Tools Used

- Microsoft Excel 2016
- Excel Formulas
- PivotTables and PivotCharts
- Slicers
- Interactive Dashboard

## Dataset

- Original records: 1,000
- Records after duplicate removal: 998
- Dataset: Synthetic sales data

## Data Cleaning

- Identified missing customer names and city values.
- Replaced missing values with "Unknown".
- Standardized region names.
- Removed duplicate records.
- Created calculated columns.

## Excel Skills

- SUMIFS
- COUNTIFS
- IF and IFERROR
- Data Cleaning
- PivotTables
- PivotCharts
- Slicers
- Dashboard Creation

## Key Performance Indicators

- Total Net Sales: ₹5,04,01,005
- Total Profit: ₹1,00,80,201
- Total Orders: 998
- Profit assumption: 20% of Net Sales

## Key Business Insights

- North was the highest-performing region.
- Electronics was the highest-selling category.
- Laptop B was the top-selling product.

## Dashboard Features

- Four KPI cards
- Five Pivot Charts
- Three interactive slicers:
  - Region
  - Category
  - Payment Mode

## Project Objective

To demonstrate practical Excel skills in data cleaning, sales analysis, data visualization, and dashboard development for an entry-level Data Analyst role.

## Disclaimer
This project uses synthetic practice data and does not represent actual company sales.
